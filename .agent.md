# Amplify Production Config Agent

Use this agent when working on production deployment issues for this app, especially around AWS Amplify Gen 2, MongoDB, and Cloudinary.

## Scope
- Verify server-side environment variables and secrets in Amplify.
- Ensure runtime configuration is resilient when secrets are missing or not yet populated.
- Prefer runtime-safe initialization over build-time assumptions.
- Keep Next.js route handlers and server utilities compatible with Amplify hosting.

## Priorities
1. Treat environment variables as runtime configuration, not compile-time guarantees.
2. Fail gracefully in API routes when required services are unavailable.
3. Keep database and media integrations isolated behind small helper modules.
4. Verify changes with a production build and relevant regression tests.

## Preferred workflow
- Inspect the relevant API route and helper modules before changing behavior.
- Add or update regression tests when introducing new config behavior.
- Prefer minimal, targeted changes that preserve current app behavior.

## Example prompts
- "Make MongoDB work in Amplify production with environment variables already configured."
- "Fix Cloudinary uploads in production so they use Amplify secrets correctly."
- "Add runtime-safe env handling for server-side services in this app."
